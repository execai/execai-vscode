# ExecAI для VS Code и Cursor

Агент [execai](https://github.com/execai/execai-agent) в сайдбаре редактора: чат со стримом, инструменты с подтверждениями, контекст активного файла — весь агентский цикл работает в CLI на твоей машине, расширение только рисует.

## Что умеет

- **Чат в сайдбаре** — стриминг ответа, блок размышлений (сворачивается), плашки инструментов с живым выводом (Bash стримит строки по мере появления)
- **Подтверждения как в TUI и веб-чате** — пять кнопок: «Разово», «Весь инструмент в сессии», «Эту команду в сессии», «НАВСЕГДА» (пишется в `permissions.json`), «Отклонить». Молчание никогда не расширяет права
- **Вопросы агента** (AskUser) — когда решение за тобой, варианты приходят кнопками
- **Контекст редактора** — активный файл и выделение прикладываются к сообщению (настройка `execai.attachContext`)
- **Изменённые файлы** — чипы под ходом, клик открывает файл
- **Вкладки чатов** вверху панели, как вкладки файлов в редакторе: все чаты проекта, клик — переключение, «×» — закрыть (чат остаётся в истории, начатый ход продолжается), перетаскивание — порядок
- **Чаты работают параллельно** (агент R6.74+): переключай вкладки во время ответа — ход продолжается и при возврате повторяется с начала. Бейджи на вкладках: пульсирующая точка — работает, зелёная — закончил и не прочитано, «?» — ждёт твоего ответа, ⏰ — запланировано пробуждение; чат, который закончил или спросил, пока ты в другом, поднимает тост с кнопкой **Открыть**. Пробуждения (`schedule_wakeup`) показываются строкой с **Сейчас** / **Отменить** и переживают перезапуск редактора
- **Кликабельные ссылки** — URL открывается в браузере, путь к файлу проекта (`internal/agent/memory.go:42`) открывает файл на нужной строке
- **Кнопки копирования** — на каждом блоке кода и на ответе целиком (копирует исходный markdown)
- **Стоп** — прервать ход; **Новый чат** — сбросить историю и сессионные разрешения
- **Терминальный запасной ход** — команда «ExecAI: Открыть в терминале» даёт полный TUI
- **Начало** (агент R7.10+) — пустой чат открывается пятью шагами с отметками: вход, модели, синк, привязка папки к проекту, вызов агента с телефона. У каждого шага — кнопка, которая его делает; закрытый один раз экран остаётся закрытым во всех проектах, вернуть его можно из меню `>_` или командой «ExecAI: Начало»
- **Моя машина** — компактная карточка из заголовка панели, меню `>_` или по команде «ExecAI: Моя машина»: машина и версия агента, аккаунт и тариф, какие источники моделей ответили и когда, что уходит в синк, доступна ли машина из веб-чата и с телефона
- **QR-код для телефона** — **Показать QR-код** в последнем шаге и **QR для телефона** в карточке: наведи камеру телефона — откроется веб-чат, где уже выбрана эта машина. Код рисуется прямо в панели, ничего не загружается
- **Субагенты** — когда агент раздаёт работу субагентам, над полем ввода появляется блок **Агенты**: состояние, название, «шаг 12/50 · ещё 38» (жёлтым, когда осталось 5 и меньше), последний инструмент и время работы; у работающих — **+25** и **Остановить**, а тот, что «упёрся в предел шагов», продолжает с того же места по **Продолжить (+25)**. Клик по строке открывает наработанное во вкладке только для чтения; **Шагов субагенту** в меню `>_` задаёт предел для новых субагентов (1–100, по умолчанию 50)
- **Задачи с сайта и с телефона** — задача, начатая в веб-чате или с телефона, открывается здесь новым чатом: на вкладке 🌐, первое сообщение «С сайта: …», тост «Пришла задача с сайта: …» с кнопкой **Открыть**, ход идёт в панели; на вопрос о разрешении можно ответить здесь или на сайте — что раньше. Нужны вход, тариф ExecAI с задачами с сайта (панель назовёт его и даст ссылку на тарифы) и папка, привязанная к проекту, — **Проект** в меню `>_`. Строка состояния и меню показывают, кто принимает задачи на этой машине, и дают **Принимать здесь**, если их держит фоновый `execai serve`
- **Тот же чат отдельным окном** — команда агента `execai ui` открывает чат без редактора: окно без вкладок и адресной строки (или вкладка браузера, если подходящего браузера нет), три оформления в светлой и тёмной теме; по SSH — пробросить порт и открыть напечатанную ссылку у себя. Руководство: [docs/ru/ui.md](https://github.com/execai/execai-agent/blob/main/docs/ru/ui.md)

  ![execai ui — чат отдельным окном](https://raw.githubusercontent.com/execai/execai-agent/main/docs/ui-demo-ru.gif)

- **Оповещения** — когда чат на экране закончил ход или ждёт ответа, а панель скрыта или окно редактора в фоне, приходит уведомление, и его кнопка **Открыть** выводит панель на этот чат; ход, остановленный тобой, не объявляется. Когда окно редактора в фоне, с обновлённым агентом уведомление на рабочем столе показывает сам агент (на своём компьютере; в удалённом сеансе остаётся уведомление внутри редактора). В `execai ui` уведомления браузера включает кнопка 🔔 в шапке страницы. В редакторе их выключает настройка `execai.notifications`
- **Сообщения синка** — то, что говорит синхронизация агента (копия, оставленная рядом с файлом, пропущенный файл, версия, взятая с сервера), видно в чате служебной строкой, с переносами строк; команды синка набираются в терминале: `execai sync`. Руководство: [docs/ru/sync.md](https://github.com/execai/execai-agent/blob/main/docs/ru/sync.md)

Источники (ExecAI / Z.ai / Kimi / Anthropic / OpenAI / Ollama…), модели, память и права настраиваются в самом CLI — расширение использует твою текущую конфигурацию. Источником может быть и **свой адрес** — любой OpenAI- или Anthropic-совместимый сервер (LM Studio, vLLM, LiteLLM, корпоративный шлюз): **Подключить источник → Свой провайдер** в меню `>_` спросит имя, тип интерфейса, адрес и ключ. Списки моделей приходят от самих провайдеров.

## Языки интерфейса

Панель и команды следуют языку интерфейса редактора: сейчас есть **английский** и **русский**, для остальных локалей — английский. Добавить язык — это два файла и ни строчки кода: `package.nls.<lang>.json` для манифеста, `l10n/bundle.l10n.<lang>.json` для рантайма и словарь в `STRINGS` в [src/webviewHtml.ts](src/webviewHtml.ts). Юнит-тест следит, чтобы во всех словарях был одинаковый набор ключей.

## Установка

1. Поставь расширение:
   - **VS Code** — Marketplace: `ExecAI`
   - **Cursor / VSCodium / Windsurf** — Open VSX: `ExecAI`
   - или вручную: скачай `.vsix` из [Releases](https://github.com/execai/execai-vscode/releases) → `Extensions: Install from VSIX…`
2. Открой папку проекта — слева появится иконка ExecAI.
3. При первом запуске расширение предложит **скачать агента** (~7 МБ) — он кладётся
   в хранилище расширения, sudo не нужен. Если execai уже стоит в PATH и достаточно
   свежий (R7.21+), используется он.

Затем войди и подключи модели прямо в панели: у шагов **Начало** для этого есть кнопки, то же есть в меню `>_` («Войти в ExecAI», «Подключить источник»).

Ставить агента вручную не обязательно, но можно:

```bash
curl -fsSL https://raw.githubusercontent.com/execai/execai-agent/main/install.sh | bash
```

## Настройки

| Настройка | По умолчанию | Что делает |
| --- | --- | --- |
| `execai.binaryPath` | `execai` | Путь к бинарю. Пусто/`execai` — плагин найдёт его в PATH или принесёт сам. |
| `execai.maxIterations` | `0` | Предел итераций инструментов на один ход (0 — из конфига execai). |
| `execai.attachContext` | `true` | Прикладывать активный файл и выделение к сообщению. |
| `execai.autoInstall` | `true` | Предлагать скачать агента, если он не найден или устарел. |
| `execai.resumeLastChat` | `true` | Продолжать последний чат проекта при открытии панели; выключено — каждый раз с чистого листа. |
| `execai.notifications` | `true` | Сообщать, когда чат закончил ход или ждёт ответа, а панель скрыта или окно редактора в фоне: внутри редактора (кнопка открывает этот чат) или уведомлением рабочего стола, пока окно в фоне. |

## Как это устроено

Расширение запускает `execai ide --cwd <папка проекта>` и говорит с ним JSON-строками через stdin/stdout. Протокол версионирован: при рассинхроне версий расширение попросит обновиться, а не сломается молча. Неотвеченный вопрос (закрыл редактор) агент считает отказом — тот же принцип, что в фоновом режиме `execai serve`.
